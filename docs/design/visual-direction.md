# Visual direction: Citizen Assist AI

Status: the initial concept was approved in the conversation and implemented as the React frontend. See `frontend-spec.md` and `../frontend-verification.md` for the implementation scope and verification.

## Confirmed direction

- React web interface with a Python backend, following the assignment requirements.
- Real public services and information checked against identifiable official sources.
- A GOV.BR-inspired portal presented as an academic FIAP-themed parody.
- Use the FIAP logo and brand reference images supplied by the user.
- Keep the project visibly identified as an independent academic project.

## Reference assets

All six original supplied images are preserved unchanged in `references/`.

- `fiap-logo-pink.png`: supplied horizontal logo, used in the initial preview.
- `fiap-favicon.png`: supplied 16-pixel favicon; use the original rather than an approximate crop.
- `fiap-logo-white-on-pink.png`: alternate logo treatment.
- `fiap-brand-dark.png`, `fiap-meetup-reference.png`, `fiap-summit-reference.png`: composition and brand references.

The initial preview uses a proposed pink of `#ed145b`, dark neutral surfaces, white backgrounds, thin separators and generous spacing. The hex value is a working design choice, not a verified official brand specification.

## Layout proposal

Preserve the recognizable portal structure: institutional header, thematic navigation, prominent service search, frequently requested topics, service cards and footer. Apply FIAP branding with a dark hero and pink accents.

Search and topic filters in the preview work on six illustrative service titles. Detail panels demonstrate content placement; the assistant is a labeled placeholder. No public-service guidance has been researched or implemented in this preview.

Proposed initial topics, pending final content selection: documents and identification, work and employment, and social assistance.
